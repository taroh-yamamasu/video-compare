# KinePair iOS

KinePair is a native SwiftUI/AVFoundation app for synchronizing and comparing two locally selected videos on iPhone and iPad. The Xcode project remains under `FormSync/` because its internal identifiers are preserved for compatibility.

## Product Identity

- App Store name: `KinePair - 動画フォーム比較`
- In-app display name: `KinePair`
- Subtitle: `フォームを2画面で同期再生`
- Current source version: `1.3.0 (1300)`
- Minimum OS: iOS/iPadOS 17.0
- Bundle ID: `com.yamamasutaro.formsync`
- StoreKit product ID: `formsync.pro.lifetime`
- Purchase type: non-consumable lifetime `KinePair PRO`

The public brand is KinePair. Do not rename the Xcode target, module, bundle ID, StoreKit product ID, Keychain service, or existing storage directories without an explicit migration plan.

## Current Features

- Select two videos with `PhotosPicker`, or start the bundled offline 2D sample comparison without Photos access.
- Set an independent comparison reference point for each video with seek and frame-step controls.
- Start synchronized playback from the common timeline rather than from the reference points.
- Display videos side by side, stacked, or overlaid without cropping their source aspect ratio.
- Shared play/pause, tap-and-drag seek, frame stepping, and playback-rate controls.
- Per-video pinch zoom and pan.
- Loop range start/end, enable/disable, and clear controls.
- Overlay opacity plus independent position, scale, and rotation adjustment for both videos.
- Long-press repeat on overlay adjustment buttons.
- Local comparison history with reopen, delete, and double-tap rename.
- Image and MP4 export with progress, cancellation, Photos save, and the iOS share sheet.
- Export the current display mode in 720p or 1080p; video export supports full/loop ranges and no/left/right audio.
- Adaptive iPhone/iPad portrait and landscape layouts; iPad landscape exposes detailed controls alongside the videos.
- Three-page first-run tutorial, one-time v1.3 update notice, settings, purchase/restore controls, and privacy-policy link.
- English, Japanese, and Korean UI with English fallback through `Localizable.xcstrings` and `ko.lproj`.
- App Store review request after three real-video comparisons with meaningful synchronized playback.

### Sample comparison

- Uses two app-authored 2D squat silhouette videos generated by `Tools/GenerateSampleVideos.swift`.
- Runs through the normal comparison engine and exposes every PRO comparison tool.
- Does not consume a full-feature trial use, create history, request Photos permission, or count toward review prompting.
- Keeps a visible `Try Your Own Videos` action before and after synchronized comparison starts.

## Access Levels

### Full-feature trial

The first three synchronized comparisons unlock the complete PRO feature set for that comparison session. A use is consumed when the user starts a synchronized comparison. Trial usage is stored in Keychain with a UserDefaults cache.

### Limited free tier

- Select two videos and set both reference points.
- Side-by-side and stacked comparison.
- `1x` and `1.25x` playback.
- Shared seek and `1/10`-second frame stepping.
- The latest local history item.
- Watermarked 720p current-frame image export.
- A small live `KinePair` watermark; screen recording shows a protection overlay.

### KinePair PRO

- Overlay comparison with opacity, position, scale, and rotation adjustment.
- `0.25x`, `0.5x`, and `0.75x` slow playback.
- Loop playback.
- Additional `1/60`, `1/30`, and `1/2`-second frame-step widths.
- Multiple local history items.
- Watermark-free image export and 1080p output.
- MP4 video export with selectable range, resolution, and audio source.

PRO is determined only from verified StoreKit 2 transactions. The local entitlement cache is used as a startup display aid, then refreshed from `Transaction.currentEntitlements` and `Transaction.updates`.

## Export Behavior

- Images reproduce the active side-by-side, stacked, or overlay layout on a black background.
- Videos use the synchronized common timeline at normal output speed regardless of preview playback speed.
- Side-by-side and stacked exports preserve each video's aspect ratio and place the videos directly adjacent without an artificial center gap.
- Overlay exports apply the current opacity, translation, scale, and rotation settings.
- Free image exports include the `KinePair` watermark; PRO and active trial exports do not.
- Temporary files are passed to Photos or the standard share sheet and are not uploaded.
- Available temporary disk space is checked before video rendering.

## History And Local Storage

- Comparison sessions and copied local video files are stored only in the app container.
- Leaving a synchronized comparison persists its current settings and marks it eligible for the one-time review request.
- The limited free tier displays the latest history item; hidden saved items reappear after PRO purchase.
- The Keychain-backed trial counter uses the existing bundle identifier as its service name.

## Privacy And Capture Protection

- Selected videos are processed entirely on device.
- The app has no account, server upload, advertising, analytics, or tracking.
- `PrivacyInfo.xcprivacy` declares no collected data or tracking and lists the required reasons for UserDefaults and disk-space APIs.
- Limited free users see a live watermark. `UIScreen.isCaptured` monitoring adds protection while screen recording is active.
- iOS does not provide a reliable way to block screenshots completely; exported free images remain watermarked.

## Build And Test

Install XcodeGen 2.42 or later, then regenerate the project before opening or archiving:

```bash
cd ios/FormSync
xcodegen generate
open FormSync.xcodeproj
```

The generated project source is `ios/FormSync/project.yml`. The shared Debug scheme references `FormSync/StoreKit/FormSync.storekit` for local purchase testing, while the `.storekit` file is excluded from the Release app bundle.

Useful verification commands:

```bash
xcodebuild \
  -project FormSync.xcodeproj \
  -scheme FormSync \
  -configuration Release \
  -sdk iphoneos \
  CODE_SIGNING_ALLOWED=NO \
  build
```

Unit tests cover trial access, Keychain restoration, feature gating, review thresholds, update-notice state, sample semantics, and backward-compatible session decoding. UI screenshot tests support English, Japanese, and Korean; App Store screenshots are under `FormSyncUITests/` and `AppStore/Screenshots/`.
